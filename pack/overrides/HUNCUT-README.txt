AOP Tools - Huncut Optimized 1.14.2

Prism Launcher importalas:
1. Add Instance
2. Import
3. Valaszd ki az aop-tools-huncut-optimized-1.14.2.mrpack fajlt.

Fullbright bekapcsolasa:
Options -> Resource Packs -> Boosted Brightness v1.2 -> Enable

A csomag nem tartalmaz fiokot, UUID-t, szerverlistat, vilagot, naplot,
kepernyokepet, Meteor-profilt, AOP presetet vagy helyi gepeleresi utat.

Az AOP Tools sajat, engedelyezett szerveren hasznalando. Nem kerul meg
szerverjogosultsagot. A Clumps szerveroldali hatasahoz a szerverre is
telepiteni kell a megfelelo Clumps verziot.

Az ExploitPreventer ismert kliensoldali resource-pack es fingerprinting
tamadasok ellen nyujt kiegeszito vedelmet.

Projekt: https://github.com/NC480/AOP-Tools
